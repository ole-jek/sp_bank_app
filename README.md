## Цель проекта  
*Создать* новую **фичу** для личного кабинета клиента по заказу IT-отдела крупного банка - *виджет*. Этот виджет 
показывает несколько последних успешных банковских операций клиента.
## Установка
Чтобы *скачать* проект себе на компьютер, используйте команду `git clone` (по мере
обновления используйте `git pull`)
## Функции
`sort_by_date` - позволяет сортировать лист со словарями по датам.  
Пример использования:
```commandline
# Входной аргумент
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
 {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},  
 {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
 {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
 
# Выход функции (сортировка по убыванию, т. е. сначала самые последние операции)
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},  
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'},  
{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},  
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]
```
`filter_by_state` - позволяет филтьтровать лист со словарями по ключу.  
Пример использования:
```commandline
# Входной аргумент
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
 {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},  
 {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
 {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
 
# Выход функции со статусом по умолчанию 'EXECUTED'
[{'id': 414288290, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
 {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]

# Выход функции, если вторым аргументом передано 'CANCELED'
[{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
 {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
```
`get_mask_account` - частично скрывает номер счета.  
Пример использования:
```commandline
73654108430135874305  # входной аргумент
**4305  # выход функции
```
`get_mask_card_number` - частично скрывает номер карты.  
Пример использования:
```commandline
7000792289606361     # входной аргумент
7000 79** **** 6361  # выход функции
```
`mask_account_card` - маскирует номер карты или счета, отделяя название от цифр.  
Пример использования:
```commandline
# Пример для карты
Visa Platinum 7000792289606361  # входной аргумент
Visa Platinum 7000 79** **** 6361  # выход функции

# Пример для счета
Счет 73654108430135874305  # входной аргумент
Счет **4305  # выход функции
```
`get_date` - позволяет получить дату в формате ***"ДД.ММ.ГГГГ"***.  
Пример использования:
```commandline
"2024-03-11T02:26:18.671407"  # входной аргумент
"11.03.2024"  # выход функции
```
