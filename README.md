##Цель проекта  
*Создать* новую **фичу** для личного кабинета клиента по заказу IT-отдела крупного банка - *виджет*. Этот виджет 
показывает несколько последних успешных банковских операций клиента.
##Установка
Чтобы *скачать* проект себе на компьютер, используйте команду `git clone` (по мере
обновления используйте `git pull`)
